# Music Orchestrator — mobile

Flutter-клиент (iOS/Android/macOS) для того же Go backend, что и веб-приложение (`../frontend/frontend`). Общая дизайн-система: те же цветовые токены, шрифты (Unbounded + JetBrains Mono, самостоятельно захостены в `assets/fonts`), тот же API-контракт (`../openapi.json`).

## Запуск

```bash
cd mobile
flutter pub get
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:18080
```

После запуска войдите серверным логином. `API_KEY` остаётся необязательным
service-token режимом и для обычного мобильного входа не нужен.

## Запуск в браузере по IP

Flutter Web раздаётся самим Go-backend, поэтому отдельный web-порт не нужен:

```bash
cd mobile
flutter build web --release
cd ..
go run .
```

После этого приложение открывается по адресу backend, например
`http://192.168.3.39:18080`. Web-клиент автоматически использует тот же origin
для API и сессионного входа.

## Запуск на физическом телефоне

Телефон и Mac должны быть в одной Wi‑Fi сети. `127.0.0.1` на телефоне — это
сам телефон, поэтому нужен LAN-адрес Mac:

```bash
ipconfig getifaddr en0
flutter devices
flutter run -d <DEVICE_ID> --dart-define=API_BASE_URL=http://<MAC_LAN_IP>:18080
```

Backend уже слушает `:18080` на всех интерфейсах. Проверить адрес с Mac можно
командой `curl --noproxy '*' http://<MAC_LAN_IP>:18080/health`. Если сборка уже
установлена, тот же адрес можно ввести в приложении: **Настройки → Подключение к
серверу**. Для локального self-hosted HTTP в iOS и Android добавлены необходимые
network/cleartext разрешения.

## Структура

- `lib/theme/` — цветовые токены и радиусы, синхронизированы вручную с `frontend/frontend/src/styles.css`; при правке палитры менять оба места.
- `lib/api/` — HTTP-клиент и модели, зеркалят `frontend/frontend/src/api/`.
- `lib/state/` — контроллеры (`ChangeNotifier`): акцент, плеер (`just_audio`), библиотека/поиск.
- `lib/widgets/`, `lib/screens/` — UI, структура повторяет разбиение экранов веб-приложения (Медиатека/Поиск/Плейлисты/Загрузки/Настройки).

## Возможности мобильного клиента

- фильтрация поиска по YouTube и SoundCloud;
- потоковое и загруженное воспроизведение через self-hosted backend;
- история «Слушай снова» на устройстве;
- создание и просмотр плейлистов, автоматическая и пользовательская обложка;
- загрузка пользовательской обложки непосредственно при создании плейлиста;
- лайк, скачивание, shuffle и три режима repeat в полном плеере;
- iOS и Android network-конфигурация для подключения к серверу в локальной сети.
