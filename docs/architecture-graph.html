🐛 Known Bugs & Architecture Issues

1. Search Race Condition

SearchPage.tsx:98-104 — debounce + TanStack Query stale data. Previous in-flight request's response can briefly appear as current results.
FIX: AbortController + discard stale responses

2. YouTube 2x Duration

SearchPage.tsx:581 + extractor.go:324 — audio element reports CDN Content-Length-based duration (video+audio container), not audio-only duration.
FIX: Prefer yt-dlp duration_seconds over audio.duration

3. iOS Media Session

SearchPage.tsx:552 — artwork missing sizes/type, uses raw external URL instead of /v1/artwork proxy.
FIX: Use artworkURL() proxy + sizes:'512x512' + type:'image/jpeg'

4. Playlist: No Add Track UI

SearchPage.tsx:319-373 — PlaylistCard has remove but no add track button.
FIX: Add track picker or search integration

5. Desktop Nav Disappears

SearchPage.tsx:133 — lg:static overrides xl:sticky, nav scrolls away between lg and xl.
FIX: Change lg:static to lg:sticky lg:top-5

6. SoundCloud Broken

extractor.go:56-110 — scsearch extractor may fail due to API lockdown; empty webpage_url causes all results to be skipped.
FIX: Fallback to info.URL when webpage_url empty + check yt-dlp SC status

7. YouTube Slow Loading

providers.go:56-68 — sequential provider search; extractor.go:263 — cold yt-dlp process per request; no stream URL caching.
FIX: Parallel providers + cache stream URLs 30-60s

8. No Infinite Scroll

SearchPage.tsx:185 — manual "Ещё 20" button, re-fetches all results from offset 0.
FIX: IntersectionObserver + true offset-based pagination
